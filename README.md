# PI-Grupo-32
Repositório para o PI do 3ºSemestre do grupo 32 do curso de ADS

Projeto desenvolvido como Projeto Integrador (PI) do 3º semestre do curso de Análise e Desenvolvimento de Sistemas.

## Sobre o projeto

Aplicação web simples para cadastro e gerenciamento de clientes de uma costureira. Os dados são exibidos em uma tabela e podem ser adicionados, editados ou excluídos diretamente no navegador.

## Funcionalidades

- Cadastro de nome completo, telefone e e-mail
- Validação do campo nome completo
- Inclusão de novos clientes
- Edição de registros existentes
- Exclusão de registros com confirmação
- Limpeza automática dos campos após o envio

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura dos arquivos

- `Index.html` — estrutura da página e do formulário
- `Styles.css` — estilos da interface e da tabela
- `script.js` — validação e operações de adicionar, editar e excluir registros

## Como executar

1. Clone o repositório:

```bash
git clone https://github.com/LuizMoassab8801/PI-Grupo-32.git
```

2. Acesse a pasta do projeto:

```bash
cd PI-Grupo-32
```

3. Abra o arquivo `Index.html` em um navegador.

## Armazenamento dos dados

Neste momento, os registros são mantidos apenas na memória da página durante o uso. Os dados não são enviados para um servidor e serão perdidos ao atualizar ou fechar o navegador.

## Observação

Os nomes dos arquivos fazem distinção entre maiúsculas e minúsculas em sistemas como Linux. Verifique se o nome referenciado no HTML corresponde ao nome real do arquivo.
